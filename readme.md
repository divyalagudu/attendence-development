# Attendance Development

This project is about analyzing student attendance data using Python and Jupyter Notebook.

## Dataset

* 90 Students
* 40 Sessions
* Attendance records in CSV format

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Files

* `attendance_90students_40sessions.csv` – Attendance dataset
* `attendence_development (1).ipynb` – Analysis notebook

## How to Run

1. Clone the repository.
2. Open the Jupyter Notebook.
3. Upload/use the CSV dataset.
4. Run the notebook cells to perform the attendance analysis.
